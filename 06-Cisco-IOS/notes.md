# Cisco IOS Commands Notes

## What is Cisco IOS?

Cisco IOS (Internetwork Operating System) is the operating system used on Cisco routers and switches.

## Cisco CLI Modes

### User EXEC Mode

Prompt:

Router>

Limited monitoring commands.

---

### Privileged EXEC Mode

Prompt:

Router#

Command:

enable

---

### Global Configuration Mode

Prompt:

Router(config)#

Command:

configure terminal

---

### Interface Configuration Mode

Prompt:

Router(config-if)#

Command:

interface gigabitEthernet0/0

---

## Important Commands

- enable
- configure terminal
- hostname
- interface
- ip address
- no shutdown
- exit
- end
- copy running-config startup-config

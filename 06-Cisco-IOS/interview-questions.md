# Interview Questions

## Q1. What is Cisco IOS?

Cisco IOS is the operating system used on Cisco routers and switches.

---

## Q2. Which command enters Privileged EXEC Mode?

enable

---

## Q3. Which command enters Global Configuration Mode?

configure terminal

---

## Q4. Which command saves the configuration?

copy running-config startup-config

---

## Q5. Which command displays interface status?

show ip interface brief

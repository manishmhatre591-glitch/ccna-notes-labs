# Cisco IOS Commands

```bash
enable

configure terminal

hostname R1

interface gigabitEthernet0/0

ip address 192.168.1.1 255.255.255.0

no shutdown

exit

end

show ip interface brief

show running-config

show startup-config

copy running-config startup-config
```

## Explanation

- enable → Enter Privileged EXEC Mode
- configure terminal → Enter Global Configuration Mode
- hostname R1 → Change router hostname
- interface gigabitEthernet0/0 → Enter interface configuration
- ip address → Assign IP address
- no shutdown → Enable interface
- exit → Exit current mode
- end → Return to Privileged Mode
- show ip interface brief → Show interface status
- show running-config → Show current configuration
- show startup-config → Show saved configuration
- copy running-config startup-config → Save configuration

# Interview Questions

## Q1. What is OSPF?

OSPF is a link-state dynamic routing protocol.

---

## Q2. Which algorithm does OSPF use?

Shortest Path First (SPF) algorithm.

---

## Q3. What is the default OSPF area?

Area 0.

---

## Q4. Which command starts OSPF?

```bash
router ospf 1
```

---

## Q5. Which command shows OSPF neighbors?

```bash
show ip ospf neighbor
```

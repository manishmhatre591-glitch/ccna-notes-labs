# OSPF Notes

## What is OSPF?

OSPF (Open Shortest Path First) is a link-state dynamic routing protocol used to exchange routing information between routers.

## Features

- Link-State Routing Protocol
- Uses SPF (Shortest Path First) Algorithm
- Supports VLSM and CIDR
- Fast Convergence
- Suitable for Medium and Large Networks

## OSPF Terminology

- Router ID (RID)
- Area
- Neighbor
- Link-State Advertisement (LSA)

## Default Area

Area 0 (Backbone Area)

## Advantages

- Fast convergence
- Efficient routing
- Scalable
- Supports large networks

## Disadvantages

- More complex than RIP
- Requires more CPU and memory

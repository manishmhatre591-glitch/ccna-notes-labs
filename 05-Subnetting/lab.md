# Lab 5 - Subnetting Practice

## Objective

Understand subnetting using a simple LAN.

## Devices

- 2 PCs
- 1 Switch

## Topology

PC0 -------- Switch -------- PC1

## IP Configuration

PC0

IP Address:
192.168.10.10

Subnet Mask:
255.255.255.0

Gateway:
192.168.10.1

PC1

IP Address:
192.168.10.20

Subnet Mask:
255.255.255.0

Gateway:
192.168.10.1

## Task

Find:

- Network ID
- Broadcast ID
- Number of Hosts
- Host Range

## Verification

Open Command Prompt

Run

ping 192.168.10.20

## Expected Result

Reply received successfully.

# VLAN Notes

## What is VLAN?

A VLAN (Virtual Local Area Network) is a logical network that divides one physical switch into multiple separate broadcast domains.

## Why Use VLAN?

- Improves network security
- Reduces broadcast traffic
- Better network management
- Separates departments (HR, Sales, IT)

## VLAN Types

- Default VLAN (VLAN 1)
- Data VLAN
- Voice VLAN
- Management VLAN
- Native VLAN

## Advantages

- Better performance
- Increased security
- Easy management
- Flexible network design

# Lab 1 - Cisco IOS Basic Commands

## Objective

Practice basic Cisco IOS commands.

## Devices Required

- 1 Cisco Router (2911)

## Steps

1. Open Cisco Packet Tracer.
2. Drag one Router.
3. Open CLI.
4. Execute the following commands.

```bash
enable
configure terminal
hostname R1
end
show version
show ip interface brief
```

## Expected Result

- Router hostname changes to R1.
- IOS version is displayed.
- Interface status is displayed.
- Router hostname changes to R1.
- IOS version is displayed.
- Interface status is displayed.

# Basic Cisco IOS Commands

```bash
enable
configure terminal
hostname R1
show version
show running-config
show ip interface brief
```

## Command Explanation

- enable → Enter privileged EXEC mode
- configure terminal → Enter global configuration mode
- hostname R1 → Change the device name
- show version → Display Cisco IOS version
- show running-config → Show current configuration
- show ip interface brief → Display interface status and IP addresses

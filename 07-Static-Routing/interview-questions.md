# Interview Questions

## Q1. What is Static Routing?

Static routing is a manually configured routing method.

---

## Q2. Which command is used to configure a static route?

ip route

---

## Q3. What is the syntax of a static route?

ip route destination-network subnet-mask next-hop

---

## Q4. Which command displays the routing table?

show ip route

---

## Q5. How do you verify connectivity?

ping

# OSI Model Notes

## What is the OSI Model?

The OSI (Open Systems Interconnection) Model is a reference model used to understand how data travels from one device to another.

## 7 Layers

### Layer 7 - Application
Provides network services to users.

### Layer 6 - Presentation
Handles encryption, compression, and translation.

### Layer 5 - Session
Establishes, manages, and terminates communication sessions.

### Layer 4 - Transport
Provides reliable data delivery using TCP and UDP.

### Layer 3 - Network
Handles routing and IP addressing.

### Layer 2 - Data Link
Uses MAC addresses and transfers frames.

### Layer 1 - Physical
Transfers bits through cables, fiber, or wireless.

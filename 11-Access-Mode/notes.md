# Access Mode Notes

## What is Access Mode?

Access Mode is used to connect end devices such as PCs, printers, IP phones, and servers to a switch.

An Access Port belongs to only one VLAN.

## Features

- Carries traffic for only one VLAN.
- Commonly used for end devices.
- Does not carry VLAN tags.

## Where is Access Mode Used?

- PC
- Laptop
- Printer
- Server
- IP Phone

## Example

PC0 → Fa0/1 → VLAN 10

PC1 → Fa0/2 → VLAN 20

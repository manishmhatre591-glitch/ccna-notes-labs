# Interview Questions

## Q1. What is Access Mode?

Access Mode allows a switch port to carry traffic for only one VLAN.

---

## Q2. Which devices connect to an Access Port?

- PC
- Laptop
- Printer
- Server

---

## Q3. Which command configures an Access Port?

```bash
switchport mode access
```

---

## Q4. Which command assigns a VLAN?

```bash
switchport access vlan 10
```

---

## Q5. Which command verifies VLAN information?

```bash
show vlan brief
```

# Interview Questions

## Q1. What is VLAN?

A VLAN is a logical network that divides a switch into separate broadcast domains.

---

## Q2. Which command creates a VLAN?

```bash
vlan 10
```

---

## Q3. Which command assigns a port to a VLAN?

```bash
switchport access vlan 10
```

---

## Q4. Which command displays VLAN information?

```bash
show vlan brief
```

---

## Q5. What is the default VLAN?

VLAN 1.

# IPv4 Addressing Notes

## What is IPv4?

IPv4 (Internet Protocol Version 4) is a protocol used to identify devices on a network using a 32-bit address.

Example:

192.168.1.10

---

## Structure of IPv4 Address

An IPv4 address has 32 bits divided into 4 octets.

Example:

192.168.1.10

Each octet ranges from 0 to 255.

---

## IP Classes

### Class A
Range:
1.0.0.0 – 126.255.255.255

Default Subnet Mask:
255.0.0.0

---

### Class B
Range:
128.0.0.0 – 191.255.255.255

Default Subnet Mask:
255.255.0.0

---

### Class C
Range:
192.0.0.0 – 223.255.255.255

Default Subnet Mask:
255.255.255.0

---

## Private IP Address Ranges

10.0.0.0/8

172.16.0.0 – 172.31.255.255

192.168.0.0/16

---

## Public IP Address

Public IP addresses are assigned by Internet Service Providers (ISP).

---

## Subnet Mask

A subnet mask identifies the network and host portions of an IP address.

Example:

255.255.255.0

# Interview Questions

## Q1. What is Inter-VLAN Routing?

Inter-VLAN Routing allows communication between different VLANs using a Layer 3 device.

---

## Q2. What is Router-on-a-Stick?

A method that uses one physical router interface with multiple sub-interfaces.

---

## Q3. Which command enables VLAN tagging?

```bash
encapsulation dot1Q <VLAN-ID>
```

---

## Q4. Which switch port mode is required between the router and switch?

```bash
switchport mode trunk
```

---

## Q5. Which command shows trunk information?

```bash
show interfaces trunk
```

# Interview Questions

## Q1. What is RIP?

RIP is a dynamic routing protocol that uses hop count to determine the best path.

---

## Q2. What is the maximum hop count in RIP?

15 hops.

---

## Q3. Which RIP version supports VLSM?

RIP Version 2.

---

## Q4. Which command enables RIP?

router rip

---

## Q5. Which command displays routing protocols?

show ip protocols

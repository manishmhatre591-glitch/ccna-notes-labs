# Interview Questions

## Q1. What is a Trunk Port?

A Trunk Port carries traffic for multiple VLANs.

---

## Q2. Which protocol is used for VLAN tagging?

IEEE 802.1Q

---

## Q3. Which command enables Trunk Mode?

```bash
switchport mode trunk
```

---

## Q4. Which command shows trunk information?

```bash
show interfaces trunk
```

---

## Q5. What is the default Native VLAN?

VLAN 1

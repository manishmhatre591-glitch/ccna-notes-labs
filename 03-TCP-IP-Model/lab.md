# Lab 3 - TCP/IP Communication

## Objective

Verify communication between two PCs using the TCP/IP Model.

## Devices

- 2 PCs
- 1 Switch

## Topology

PC0 ----- Switch ----- PC1

## IP Address

PC0
192.168.1.10/24

PC1
192.168.1.20/24

## Steps

1. Add two PCs and one switch.
2. Connect both PCs to the switch.
3. Configure IP addresses.
4. Open Command Prompt on PC0.
5. Run:

ping 192.168.1.20

6. Verify successful replies.

## Result

Communication is successful using the TCP/IP protocol suite.

# TCP/IP Model Notes

## What is TCP/IP?

TCP/IP (Transmission Control Protocol/Internet Protocol) is the protocol suite used for communication on the Internet.

## Layers of TCP/IP Model

### 1. Application Layer
- HTTP
- HTTPS
- FTP
- DNS
- SMTP

### 2. Transport Layer
- TCP
- UDP

### 3. Internet Layer
- IP
- ICMP

### 4. Network Access Layer
- Ethernet
- MAC Address

## Difference Between OSI and TCP/IP

| OSI | TCP/IP |
|-----|---------|
| 7 Layers | 4 Layers |
| Reference Model | Protocol Suite |
| Developed by ISO | Developed by DoD |

# Trunk Mode Notes

## What is Trunk?

A Trunk Port carries traffic from multiple VLANs between switches.

Unlike an Access Port, a Trunk Port can carry multiple VLANs using VLAN tags.

## Why is Trunk Used?

- Connect two switches
- Carry multiple VLANs
- Extend VLANs across the network

## IEEE Standard

802.1Q

## Native VLAN

By default, VLAN 1 is the Native VLAN.

Native VLAN traffic is sent without a VLAN tag.

## Difference Between Access and Trunk

| Access Mode | Trunk Mode |
|-------------|------------|
| One VLAN | Multiple VLANs |
| Used for PCs | Used between Switches |
| Untagged Traffic | Tagged Traffic (802.1Q) |

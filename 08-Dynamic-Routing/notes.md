# Dynamic Routing Notes

## What is Dynamic Routing?

Dynamic Routing is a routing method where routers automatically exchange routing information using routing protocols.

Unlike Static Routing, routes do not need to be configured manually for every network.

## Advantages

- Automatic route updates
- Easy to manage
- Suitable for large networks
- Adapts to network changes

## Disadvantages

- Uses CPU and memory
- More complex than static routing

## Common Dynamic Routing Protocols

- RIP (Routing Information Protocol)
- OSPF (Open Shortest Path First)
- EIGRP (Cisco Proprietary)

## Static Routing vs Dynamic Routing

| Static Routing | Dynamic Routing |
|---------------|-----------------|
| Manual | Automatic |
| Small Networks | Medium & Large Networks |
| Low CPU Usage | Higher CPU Usage |
| No Route Updates | Automatic Updates |

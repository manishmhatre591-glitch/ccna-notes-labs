# Lab 8 - Dynamic Routing Overview

## Objective

Understand how Dynamic Routing works before configuring routing protocols.

## Devices

- 2 Routers (2911)
- 2 PCs

## Topology

PC0 ---- R1 ---- R2 ---- PC1

## Activity

1. Configure IP addresses on all interfaces.
2. Verify connectivity between directly connected routers.
3. Observe the routing table using:

```bash
show ip route
```

4. Notice that remote networks are not reachable until a routing protocol is configured.

## Result

Successfully understood the need for Dynamic Routing protocols.

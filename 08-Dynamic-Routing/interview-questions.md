# Interview Questions

## Q1. What is Dynamic Routing?

Dynamic Routing allows routers to automatically exchange routing information.

---

## Q2. Name three Dynamic Routing protocols.

- RIP
- OSPF
- EIGRP

---

## Q3. Which is better for large networks?

Dynamic Routing.

---

## Q4. What is the main advantage of Dynamic Routing?

Automatic route updates.

---

## Q5. Which command shows configured routing protocols?

show ip protocols
